## The official answer changed

React Native's own getting-started guide now says to use a framework for new apps, and the only framework it recommends is Expo. You create a project with `npx create-expo-app@latest`. Building without a framework is still supported through the React Native Community CLI, but it's no longer the default path.

The old reason to avoid Expo, "you can't use custom native code", no longer holds. Expo generates the `ios` and `android` projects for you from your config. That's called Continuous Native Generation. Config plugins apply your native changes every time those projects are generated.

## Expo is the default for new apps

<ToolFacts tool="Expo" price="Free framework; EAS from $0 (Free plan)" runsOn="iOS, Android, web" license="Open source (MIT)" />

Expo gives you file-based routing, a standard library of native modules and tooling around React Native. You start in seconds:

```sh
npx create-expo-app@latest my-app
cd my-app
npx expo start
```

Expo Go, the app you install on your phone, is a quick playground, but it only runs libraries already in the Expo SDK. For anything else you make a development build: a debug build of your own app that can include any native library. When you need the native projects, `npx expo prebuild` generates them from your `app.json` and config plugins.

The framework is free. EAS, Expo's cloud service, is optional. The Free plan includes 15 Android and 15 iOS builds a month on a low-priority queue. Starter costs $19 a month with $45 of build credit. Production costs $199 a month with $225 of credit. EAS Build also lets you build iOS apps without owning a Mac.

## The React Native CLI is for full manual control

<ToolFacts tool="React Native CLI" price="Free" runsOn="iOS, Android" license="Open source (MIT)" />

The Community CLI creates a project with the `ios` and `android` folders committed in your repo. You set up Xcode, Android Studio, CocoaPods and the SDKs yourself, then edit native code directly.

```sh
npx @react-native-community/cli@latest init MyApp
```

That makes sense in two cases: adding React Native to an existing native app, or a team with iOS and Android developers who want to own every native file. You also own the pipeline. CI builds, code signing and store submission are yours to set up.

Over-the-air updates need a plan too. Microsoft retired App Center, CodePush's old home, on March 31, 2025. It published a standalone CodePush server you can run yourself. Or you can add Expo's update library to a bare app:

```sh
npx install-expo-modules@latest
npx expo install expo-updates
```

## How I set up a new Expo project

I start every new React Native app with Expo now, and the setup I recommend is the one Expo's docs push you toward. Use development builds instead of Expo Go as soon as you add your first native library, and keep the generated `ios` and `android` folders out of Git, because prebuild recreates them.

Build profiles in `eas.json` keep development, preview and production apart. The first build I run is a development build:

```sh
eas build --profile development --platform android
```

I'd only start from the bare CLI today when React Native is going into an existing native app. For everything else, the time Expo saves on builds, signing and updates goes straight into the product.

## How to choose in 30 seconds

- **A new app:** Expo.
- **iOS builds without a Mac:** Expo with EAS Build.
- **Push JavaScript fixes without a store review:** Expo with EAS Update.
- **React Native inside an existing native app:** React Native CLI.
- **Native developers who want to own the native folders:** React Native CLI, and you can still add Expo modules.

## FAQ

### Does React Native recommend Expo?

Yes. React Native's getting-started guide recommends using a framework for new apps, and Expo is the only framework it lists.

### Can I write native code with Expo?

Yes. Use a development build instead of Expo Go, then add native changes through config plugins or local native modules. `npx expo prebuild` generates the `ios` and `android` projects with your changes applied.

### Is Expo free?

The framework is free and open source. EAS cloud services have a Free plan with 15 Android and 15 iOS builds a month. Paid plans start at $19 a month.
