## Why look past Obsidian at all?

First, the good news: since February 2025 Obsidian is free for work, so cost isn't a reason to leave. Your notes are plain Markdown files in a folder you control.

The reason people look elsewhere is the app itself. Obsidian is closed source. Your files are safe either way, but if you want software you can inspect, fork or keep running no matter what the company decides, you need an open-source app. That's what this list covers.

## Zettlr is the closest to Obsidian's plain files

<ToolFacts tool="Zettlr" price="Free" runsOn="Windows, macOS, Linux" license="Open source (GPL-3.0)" />

Zettlr is a Markdown editor that works on the folders you already have. It doesn't create its own file structure or invent special syntax, so your notes stay ordinary `.md` files that Obsidian, VS Code or any editor can open. That also makes switching back and forth painless.

It leans toward writing and research: citations, a Zettelkasten-style workflow and exporting to other formats. It's desktop only and funded by donations.

## Joplin gives you free, encrypted sync

<ToolFacts tool="Joplin" price="Free; optional Joplin Cloud plans" runsOn="Windows, macOS, Linux, iOS, Android, terminal" license="Open source (AGPL-3.0)" />

Joplin organizes notes into notebooks and tags, closer to Evernote than Obsidian. Its strongest point is sync: you can sync for free through Dropbox, OneDrive, Nextcloud, WebDAV, S3 or a local folder, with end-to-end encryption. If you'd rather not manage that, Joplin Cloud is a paid service from the same team.

The trade-off is storage. Joplin keeps notes in its own database, not as loose files in your folders. You write in Markdown and can export everything as Markdown, but you don't edit the files directly.

## Logseq is for outliners, but choose the version

<ToolFacts tool="Logseq" price="Free" runsOn="Windows, macOS, Linux, iOS, Android" license="Open source (AGPL-3.0)" />

In Logseq every bullet is a block. You can link to it, reference it somewhere else or embed it, which suits daily journaling and connecting small ideas.

Logseq is in the middle of a big change, so check which version you install. **Logseq OG**, the original app, stores your graph as Markdown files. It's now in maintenance mode, with fixes but no new features. **Logseq 2.0**, the database version, stores everything in SQLite. It adds a new mobile app and real-time collaboration, but it's still in beta, and the team recommends regular backups because data loss is possible. A "Markdown Mirror" feature writes a Markdown copy of a database graph to disk. Edits made in those files don't flow back yet.

## Trilium handles deep hierarchies

<ToolFacts tool="Trilium" price="Free" runsOn="Windows, macOS, Linux, self-hosted server" license="Open source (AGPL-3.0)" />

Trilium is built for large personal knowledge bases. Notes form a tree with no separate folders, since any note can hold sub-notes. One note can also appear in several places in the tree. Sync runs through a server you host yourself.

The project now lives on as the community-led successor to the original Trilium, under the same name and license. There are no paid tiers, accounts or paywalls. Like Joplin, it stores notes in its own database rather than as plain files.

## How I keep my notes portable

I use Obsidian every day, and the reason I'm comfortable with a closed-source app is that my notes aren't locked in. They're Markdown files. One setting makes them even more portable: under Settings → Files and links, turn off "Use [[Wikilinks]]" so Obsidian writes standard Markdown links that any editor understands.

If you're choosing an alternative, apply the same test I use for any notes app: can you walk away with plain files tomorrow? Zettlr passes it fully. Joplin and Trilium need an export. Logseq depends on which version you run. Pick based on that, not on the feature list.

## How to choose in 30 seconds

- **Plain Markdown files with an open-source app:** Zettlr.
- **Free, encrypted sync to your phone:** Joplin.
- **Outlines and daily notes:** Logseq, OG for files, 2.0 if you can live with a beta.
- **A big knowledge base on your own server:** Trilium.
- **You don't care about open source:** stay on Obsidian. It's free for work.

## FAQ

### Is Obsidian free for commercial use?

Yes. Since February 2025 anyone can use Obsidian at work for free. The commercial license is optional.

### Does Logseq still store notes as Markdown?

Logseq OG does, and it's in maintenance mode. Logseq 2.0, the database version, stores notes in SQLite and can write a Markdown copy to disk with its Markdown Mirror feature.

### Can I sync Joplin for free?

Yes. Joplin syncs for free through Dropbox, OneDrive, Nextcloud, WebDAV, S3 or a local folder, with optional end-to-end encryption.
