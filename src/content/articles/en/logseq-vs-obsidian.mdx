## Pages versus blocks

**Obsidian** works like a folder of documents. You write a note, put it in a folder and link it to other notes. Long paragraphs and headings feel natural. **Logseq** is an outliner. Everything is a bullet, and every bullet is a block you can link to, reference or embed somewhere else. Daily journal pages are the default way in.

Here's the same reading note in each. In Obsidian, properties go at the top of the file and a block gets an ID you link to:

```markdown
---
type: book
author: Cal Newport
---

Deep work needs long, uninterrupted blocks of time. ^deep-work-time
```

Elsewhere you link to that exact paragraph with `[[Deep Work#^deep-work-time]]`. In Logseq, properties use `::` and a block is referenced by its ID in double parentheses:

```markdown
- type:: book
  author:: Cal Newport
- Deep work needs long, uninterrupted blocks of time.
```

Elsewhere you write `((block-id))` and Logseq shows that block's text inline. Both styles are Markdown underneath, but neither link syntax is standard Markdown. Other editors will show it as plain text.

## Logseq is an outliner in transition

<ToolFacts tool="Logseq" price="Free" runsOn="Windows, macOS, Linux, iOS, Android" license="Open source (AGPL-3.0)" />

Logseq's strength is the block. Write a thought once, reference it from any page, and every reference stays in sync. Its query language lets you pull blocks by tag, property or date into any page. Daily journals make it easy to capture first and organize later.

The issue in 2026 is which Logseq to use. **Logseq OG** stores your graph as Markdown files and now gets only fixes, no new features. **Logseq 2.0**, the database version, stores everything in SQLite and adds a new mobile app and real-time collaboration. It's still in beta, and the team says data loss is possible, so back up regularly. Its Markdown Mirror writes a Markdown copy of your graph to disk. Edits in those files don't sync back yet.

## Obsidian is the stable choice for Markdown files

<ToolFacts tool="Obsidian" price="Free; Sync from $4/mo, yearly" runsOn="Windows, macOS, Linux, iOS, Android" license="Proprietary, free for any use" />

Obsidian stores notes as Markdown files in a folder on your disk, and it's free for any use, including work since February 2025. Optional Sync starts at $4 a month on a yearly plan. You can also sync the folder yourself with iCloud, Syncthing or Git.

Links, backlinks and a graph view connect notes. Since version 1.9, the Bases plugin turns notes into database views: table, cards, list or Kanban, all built from the properties in your files. A large plugin community covers almost anything else, including outlining.

The trade-off is that Obsidian is closed source. Your files stay fully readable without it, but you can't inspect or fork the app.

## My advice for 2026

I've used both, and right now my advice depends on how much risk you can take with your notes. Logseq's block references are still the best I've used for daily journaling. But the app is in the middle of moving from files to a database, and I'd never put notes I can't afford to lose into beta software without backups.

If you choose Logseq OG, keep your graph folder in Git or another backup, and know it won't get new features. If you choose Logseq 2.0, back up the SQLite database regularly, as the team recommends. If you want stability today, Obsidian with a daily-notes template gets you most of the journaling workflow, on files you fully own.

## How to choose in 30 seconds

- **Long-form notes in plain files:** Obsidian.
- **Bullets, journals and block references:** Logseq.
- **Open source required:** Logseq, or Zettlr if you want files like Obsidian's.
- **You can't risk beta software:** Obsidian, or Logseq OG with its feature freeze.

## FAQ

### Is Logseq still Markdown-based?

The original app, now called Logseq OG, is, and it's in maintenance mode. Logseq 2.0, the database version, stores notes in SQLite and can mirror them to Markdown files on disk.

### Is Obsidian free for work?

Yes. Since February 2025 anyone can use Obsidian at work for free. A commercial license is optional.

### Can I move my notes between them?

With Logseq OG and Obsidian, mostly yes, because both read Markdown files. Block references and property syntax differ, so those links need fixing after a move.
