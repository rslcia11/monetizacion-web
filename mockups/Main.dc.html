Bruno keeps your requests in the repo

Price
Free, paid team plans
Runs on
Windows, macOS, Linux
License
Open source

Bruno saves every request as a plain text file inside your project. When someone changes an endpoint, the request changes in the same pull request as the code, and the review covers both. There's no account to create and no cloud sync to switch off.

Worth it if

  • you review API changes in pull requests
  • you don't want another account

Hoppscotch needs nothing installed

Hoppscotch opens in a browser tab. On a locked-down work laptop where you can't install software, that alone decides it. It's also open source, so you can host it yourself if your company won't send requests through someone else's server.
